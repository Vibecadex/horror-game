# Rejected concept frames

These four were seeded from the same canonical still and then broke the room. They stay here so the failure is visible. They are not art direction.

| File | What it got wrong |
| --- | --- |
| `reverse-open-door.jpg` | The far opening became a traversable hall. The reverse view is the low cutaway and the depth of the same room. Wet cyan is painted on the floor. |
| `wide-truss.jpg` | A ceiling truss, extra red lamps, and cyan floor paint. The fight has open air overhead and two or three pin-sized red practicals. |
| `crawl-fence.jpg` | A chain-link opening, a fourth small creature, button eyes and bows, and painted cyan. The encounter has three stitchlings of the same family. |
| `pipes-corridor.jpg` | The left pipe run is useful as a massing note only. The frame turns it into a corridor with a roof, spotlight rows, and a large red pendant. The red practical stays a few pixels wide. |
| `wide-vault-wheel.jpg` | The sides are pipes and cabinets, and the air above the fight stays open. The far door became a vault wheel large enough to be a second wheel. The bulkhead already has one locking wheel. |

Left-wall pipes are already `SM_RoomPipeRack`, `SM_ShellPipeStandoff`, `SM_DressPipeElbow`, `SM_DressPipeHanger`, `SM_DressFlangeJoint`, `SM_DressDripTray`, and `SM_DressMeter`. No new pipe family comes from the corridor frame.
