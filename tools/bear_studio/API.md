# Bear Studio local API

The studio runs at `http://127.0.0.1:8472`, independently of the scanner and Unreal. It uses Python's standard library. Run `python tools/bear_studio/server.py`; optional `--port`, `--data-dir` and `--no-seed` flags are available. Default data lives under ignored `.team-local/bear-studio`. The scanner address comes from `BEAR_SCANNER`, then `tools/project-settings.local.json` `bear_scanner_url`; the normal scanner HTTPS default is used otherwise. Scanner requests are GET only.

All responses are JSON except static pages and files. Errors are `{error: "message"}` with an appropriate HTTP status. Mutation requests must originate from this studio; local scripts without an Origin header are allowed. IDs are generated by the server, not filesystem paths.

## Catalogue and import

- `GET /api/health` → `{ok:true, app:"bear-studio", scannerUrl, version:1, workspace, dataDir}`. Absolute workspace/data paths let the launcher avoid reusing another checkout's service.
- `GET /api/scanner/scans` → `{available:true, scans:[...]}` or `{available:false, scans:[], error}`. Failed and unfinished scans remain visible but cannot be imported.
- `GET /api/bears` → `{bears:[Bear]}`.
- `GET /api/bears/{id}` → `Bear` directly.
- `POST /api/import/scanner` JSON `{scanId}` → `{bear:Bear, imported:boolean}`. Only a finished scan can import. Its GLB, report and available allowlisted sidecars are copied, hashed and served from the studio. The scanner source is never modified.
- `POST /api/import/local` with raw self-contained GLB bytes, `Content-Type: model/gltf-binary`, `X-Filename: Rupert.glb` → `{bear:Bear, imported:boolean}`. No multipart encoding. Browsers should send `encodeURIComponent(file.name)` for Unicode filenames; the server decodes once, then rejects path separators and drive prefixes. Identical local sources are idempotent. Display filenames are metadata, never interpreted as a destination path.
- `PATCH /api/bears/{id}` JSON `{expectedRevision, name?, tags?, notes?, role?, reviewStatus?, draftRecipe?}` → `Bear`. Omit fields to preserve them. `reviewStatus`: `unreviewed`, `needs-work` or `approved`. A stale `expectedRevision` returns **409**. Draft recipe is a JSON object or null. Metadata accepts up to 32 tags, 80 characters each; notes up to 20,000 characters. Saving draft landmarks does not create a rig.
- `GET /api/bears/{id}/history` → `{history:[...]}`, newest first. Import, metadata, rig and test events are retained.

`Bear` fields:

```json
{
  "id":"bear_0123456789abcdef", "name":"Bundled real bear (prebuilt sample)",
  "tags":[], "notes":"", "role":"prop", "reviewStatus":"unreviewed",
  "revision":1, "created":"UTC ISO timestamp", "updated":"UTC ISO timestamp",
  "sourceRevision":1, "sourceSha256":"hex", "modelUrl":"/assets/.../model.glb",
  "thumbnailUrl":"/assets/.../thumb.webp", "sourceReport":{}, "sourceStats":{},
  "source":{"kind":"bundled-sample", "scanId":"...", "provenance":{}},
  "sources":[], "draftRecipe":null, "rigStatus":"unrigged", "rigs":[], "tests":[]
}
```

`thumbnailUrl` is null when no thumbnail exists. Source stats include `meshCount`, `triangles`, `vertices`, `lods`, `skins`, `animations`, `animationNames` and optional `bounds`. Geometry counts describe all GLB meshes; each `lods` entry gives individual mesh counts. The bundled source is seeded once, labelled **prebuilt sample**, and retains its existing source warnings and provenance. It is not a reconstruction performed by this studio. A changed scanner model creates another immutable source revision on the same bear and resets review/draft state; prior rigs and tests remain historical.

## Bear-pack imports

`POST /api/import/pack`: raw ZIP bytes, `Content-Type: application/zip`, percent-encoded `X-Filename` header; response `{bear, imported}`. Maximum compressed/expanded size is 128 MiB, with the existing 64 MiB model limit. Supply one bear pack, either at the archive root or in one directory. No archive files are extracted to the filesystem. Traversal, duplicate entries, unsupported formats, missing files and hash/size mismatches fail before a catalogue write.

The supported contract is `bear-pack`, `formatVersion: 1`, metres, right-handed, +Y up, +Z front. The manifest names the artifacts; supported roles are retained under the catalogue's canonical filenames. `source.pack` contains the upstream manifest without transport URLs or rebuild state. `/assets/{id}/sources/{revision}/pack-manifest.json` and `landmarks.json` retain provenance and rig-readiness evidence. The Studio's own `manifest.json` remains separate.

`POST /api/import/scanner` uses `/api/v1/bears/{scanId}` and verifies every declared artifact against its manifest, then rechecks revision/version after download. Only an absent endpoint (404) permits the existing legacy scan API path.

Idempotence covers all retained source files. A report/landmark-only change creates a new immutable source revision and marks prior rigs/tests stale. Lower pack versions receive 409. Offline packs have their own `pack:{id}` collection identity; live imports remain `scanner:{origin}#{id}`.

## Rig revisions

`POST /api/bears/{id}/rigs` JSON:

```json
{
  "sourceRevision":1,
  "sourceSha256":"the source hash from Bear",
  "recipe":{},
  "validation":{"checks":[]},
  "glbBase64":"base64 encoded complete exported skinned GLB"
}
```

Response: `{bear:Bear, rig:Rig}`. Source revision and hash must match the current source. The rig GLB must be self-contained, parse correctly, contain a real skin, valid joint references and nonempty normalized `JOINTS_0`/`WEIGHTS_0`. Animation is optional and recorded separately. The server repeats structural checks; client validation is retained as reported evidence, not trusted as server validation. Saving a rig creates immutable GLB, recipe, validation and manifest files. It remains a **draft rig requiring visual inspection**. Source bytes are never replaced.

If a recipe or draft recipe embeds `sourceRevision` or `sourceSha256`, these must also match the current source. A recipe copied from another source receives **409**; the selected bear is not silently relabelled.

`Rig`: `{revision,sourceRevision,sourceSha256,sha256,created,modelUrl,recipeUrl,validationUrl,manifestUrl,recipe,validation,structuralValidation,stats,status:"draft",stale}`. `stale` means the source revision differs from the bear's current source. Rig save increments the bear revision and resets review to `unreviewed`.

## Tests

`POST /api/bears/{id}/tests` JSON `{rigRevision, suite, results, notes?}` → `{bear:Bear, test:Test}`. `results` can be an array of check records or a JSON object. `suite` is a short nonempty name. The named saved rig must exist; tests cannot attach to an unsaved skeleton overlay. Records pin the rig and source revisions and retain supplied evidence without converting it into independent visual approval.

`Test`: `{id,rigRevision,sourceRevision,created,suite,results,notes,stale}`.

## Files and limits

- `/assets/{bearId}/sources/{revision}/{name}` serves only owned source `model.glb`, `report.json`, `thumb.webp`, `collider.json`, `cameras.json`, `landmarks.json`, `pack-manifest.json`, `manifest.json`.
- `/assets/{bearId}/rigs/{revision}/{name}` serves only owned rig `model.glb`, `recipe.json`, `validation.json`, `manifest.json`.
- `GET /api/bears/{id}/manifest` downloads the current catalogue record including source identities and revision references.
- Fixed read-only animation source routes: `/library/quaternius/model.glb`, `/library/quaternius/provenance.json`, `/library/quaternius/license.txt`. These serve the retained creator release under `Assets/ThirdParty/QuaterniusUAL`; they do not fetch a URL or mutate the library. Retargeted clips remain derived drafts requiring inspection.
- GLB uploads have a 64 MiB limit; rig JSON has a 90 MiB limit. External GLTF buffer/image URIs are refused. No arbitrary local path, URL fetch, executable or Unreal authoring endpoint is exposed.
- Catalogues remain usable if the scanner is offline. SQLite and copied bundles persist across browser and service restarts. The service binds loopback only; it does not change firewall rules or certificate trust.
