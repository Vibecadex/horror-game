# Contact alternatives V1 — preregistered protocol

Prepared 8 October 2026 before new candidate authoring. [Machine-readable protocol](protocol.json).

The current evidence does not uniquely identify wrist or belly/leg ownership. The next experiment compares one conservative, explicitly authored boundary with the frozen baseline, keeping the original geometry and UVs intact. It does not repeat the already explored face-1056 relabel as a newly discovered anatomical result.

First select one contact and save the exact disputed face set and proposed assignment map. Selection must be justified against the existing textured/clay views; old weights and labels are hints only. Where visible evidence does not discriminate, say the choice is authored. Do not infer hidden photographed anatomy.

Render the same cameras with the baseline, proposed map, opaque torso, isolated limb and ghost context. Measure changed triangle area, connectivity, attachment reach and preservation. Record which observation supports or contradicts the proposed boundary. A cleaner graph cannot select the winner.

The deterministic `experiment-check` command establishes exact input identity and preserves the protocol before candidate construction. Its pass means **ready to author a diagnostic candidate**, not anatomy approved or M1 complete. Candidate authoring, independent visual review and any subsequent reconstruction remain separate work items.
